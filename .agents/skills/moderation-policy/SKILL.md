# 게시글 검수 기준

## 금지 게시물
| 유형 | 예 | 기본 판정 |
|---|---|---|
| 가격 담합 유도 | "이 가격 밑으로는 팔지 맙시다" 결의글, 매물 가격 하한 합의 | 삭제 권고 |
| 집단 신고 독려 | 정상 매물을 허위매물로 신고하자는 글, 특정 중개사 항의 조직 | 삭제 권고 |
| 특정 대상 저격 | 개인·중개사무소·단지를 실명으로 비방 | 보류(사실 서술로 수정 요청) |
| 홍보·제휴 | 특정 매물·중개사·강의 홍보, 경제적 대가 미표시 추천 | 삭제 권고 |
| 개인정보 노출 | 연락처, 계약서·등기 원본 게시 | 즉시 가림 권고 |
| 저작물 통째 게재 | 영상 자막·유료 자료 전문 게시 | 보류(링크와 자체 요약으로 수정 요청) |

`config/forbidden_phrases.json`의 패턴은 기계적으로 잡히는 표현만 다룬다. 패턴에 안 걸려도 맥락상 담합·신고 독려면 위 기준으로 판정한다.

## 판정
- `통과` / `보류`(사람 확인 또는 수정 요청) / `삭제 권고`. **애매하면 보류**한다.
- 모든 판정에 사유를 붙인다: 어떤 기준, 어떤 문장, 어떻게 고치면 되는지.
- 삭제·제재의 실행은 사람이 한다. 반복 위반자에 대한 단계적 제재도 사람이 정한다.

## 판정 사유 형식
`[판정] 게시글 id | 기준: 가격 담합 유도 | 문장: "…" | 사유: 특정 가격 이하 거래를 하지 말자는 결의 | 수정 제안: 삭제 권고(대체 표현 없음)`

## 하지 않는 것
- 사유 없는 삭제, 한 문장만 보고 게시자 평가하기.
- 담합·신고 독려 글을 "의견"이라는 이유로 통과시키기.
