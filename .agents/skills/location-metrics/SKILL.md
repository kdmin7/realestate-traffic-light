# 입지 지표 정의

지표는 축별로만 산출하고 하나의 종합점수로 합치지 않는다. 모든 지표는 A·B 등급이며 출처와 기준일이 필요하다.

| 축 | 지표 키(예) | 의미 | 출처 후보 | 주의 |
|---|---|---|---|---|
| 학군 | `school_stats`, `student_trend` | 학교 공시 지표, 학생 수 추이 | 학교알리미 | 학령인구 감소, 학군 조정 가능성. 통학구역은 최신 공고 확인 |
| 상권 | `store_count`, `foot_traffic`, `vacancy` | 점포 수, 유동인구, 공실률 | 소상공인시장진흥공단 상가(상권)정보, 한국부동산원 통계 | 변동이 빨라 갱신 주기를 명시 |
| 역세권 | `station_walk_min`, `line_status` | 실제 도보 시간, 노선 상태 | 공식 철도 사업 정보(국토교통부·국가철도공단·지자체 공고) | 직선거리로 대체하지 않는다 |
| 가격 부담 | `avg_price_84`, `pir` | 84㎡ 평균 실거래가, 소득 대비 가격 | 국토교통부 실거래가 공개시스템, 국가통계 | 대표 면적·연식 조건을 명시 |
| 가격 경로 | `price_series` | 실거래 시계열(상승·하락 구간 모두) | 국토교통부 실거래가 공개시스템 | 표본이 적은 달은 표시 |

## 노선 상태 배지
`line_status`는 `운행 중` / `착공` / `계획` 중 하나로 쓴다. **`계획` 단계는 사실 점수에 넣지 않고 "기대 요인"으로 분리해 E 등급 또는 표시 전용으로 둔다.** 계획 노선의 프리미엄은 사실이 아니라 기대다.

## 하지 않는 것
- 인접 지역 대비 격차를 "저평가"라고 부르기. `인접 ○○ 대비 평균 실거래가 격차 -N% (기준일)`처럼 사실로만 쓴다.
- 출처의 이용 조건(공공누리 유형, API 약관)을 확인하지 않고 저장하기. 민간 시세는 재배포 제한을 약관에서 확인한다.
- 갱신 주기를 추정해서 적기. 공시 주기는 출처에서 확인하고 `board_policy.json`의 한도와 맞춘다.
