# 예산 게이트

## 명세
```
구매가능가격 = 자기자금 + 대출가능액 - 부대비용
대출가능액   = min( 가격 x LTV,  가격 구간별 한도,  DSR 기준 상환 가능 원금 )
부대비용     = 가격 x (취득세율 + 기타 부대비용 비율)
```
- 모든 규칙 값은 `rules/rules.json`에서 온다. 값이 null이거나 `status`가 `verified`가 아니면 **예외를 던진다**(실패는 닫는다).
- 가격 구간별 한도는 계단식이라 가격이 오르면 한도가 줄어들 수 있다. 이진 탐색이 아니라 순차 탐색을 쓴다.
- 지역의 규제지역 여부(`regulated`)에 따라 LTV와 스트레스 금리가 달라진다. 지역별로 계산한다.
- 구매력을 넘는 지역은 `affordable`에 넣지 않고 `overBudget`에 부족 금액(`shortfall`)과 함께 분리한다.
- 후보는 우선순위 지표의 **파레토 전선**에서만 고른다. 종합점수를 만들지 않는다.

## 프로필 입력
`equity`(자기자금), `annualIncome`, `existingAnnualRepayment`, `interestRate`(연이율, 소수), `loanYears`, `regulated`. 금액은 원 단위.

## 개인정보 원칙
소득·자산 입력값은 브라우저 안에서만 쓴다. 서버·에이전트로 보내지 않고, 로컬스토리지나 쿠키에도 저장하지 않으며, 로그에 남기지 않는다.

## 변경 시 절차
1. `web/budget-gate.js`를 수정한다.
2. `node tests/budget-gate.test.js`를 실행해 통과를 확인한다. 테스트의 규칙 값은 **테스트 전용 가상 값**이며 `rules.json`에 복사하지 않는다.
3. 예산 초과 후보가 `candidates`에 없다는 테스트, 규칙 미검증 시 예외 테스트를 지우지 않는다.

## 하지 않는 것
- 규칙 값을 코드에 하드코딩하기, 실패 시 기본값으로 대체하기.
- 결과에 확률이나 "가능성 N%"를 붙이기.
