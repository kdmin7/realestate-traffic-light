# 등급 정의와 경계 사례

| 등급 | 정의 | 경계 사례 |
|---|---|---|
| A | 공식 기관이 발표한 값을 가공하지 않고 옮긴 것 | 실거래가 공개시스템의 거래 건수 -> A. 기관이 낸 통계표라도 우리가 반올림·합산했다면 B |
| B | 규칙 테이블이나 명시된 산식을 적용한 계산 결과 | 구매력 계산, 지표 정규화 점수, 실거래 시계열의 변화율 |
| C | 사람의 해석과 주장 | 유튜버가 "학군 프리미엄은 이미 반영됐다"고 말한 것. 그 안의 숫자가 공식 통계와 일치해도 견해 자체는 C |
| D | 회원 개인의 거래·거주 경험 | 표본이 하나(n=1). 집계해서 만족도 비율로 만들지 않는다 |
| E | 앞으로에 대한 예측 | 금리·시세 전망. 확률 수치 없이 보수·기준·낙관 범위와 가정 조건으로만 |

## 자주 하는 실수
- 견해 속 숫자를 A로 올리기: 숫자는 공식 출처에서 다시 확인한 뒤 그 출처로 A 항목을 새로 만든다.
- 기준일 없이 "최근"이라고만 쓰기.
- 2차 자료(블로그, 뉴스)를 출처로 A를 달기: 원출처를 찾지 못하면 등급을 달지 말고 저장을 보류한다.
- 규칙 값을 코드나 초안에 직접 적기: 규칙은 항상 `rules/rules.json`에서 조회한다.
