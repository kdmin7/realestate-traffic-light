# 지역 카드 초안 형식

`validate_board.py`가 이 형식을 그대로 검사한다. 형식이 틀리면 발행되지 않는다.

```markdown
---
slug: songpa                      # 파일명과 같아야 한다(영문 소문자·숫자·-_)
region: 송파구
as_of: 2026-09                    # 초안 기준일 (오래되면 반려)
status: draft                     # draft 또는 reviewed
rules_as_of: 2026-09-01           # 대출·구매력 내용이 있을 때만 필수
sources: [data/re-market-data/songpa_raw.md, data/re-trend-risk/songpa_scores.md]
---
# 송파구

## 요약
- 가격 부담: 84㎡ 평균 실거래가 12.3억 [A | 국토교통부 실거래가 공개시스템 | 2026-09]

## 사실 패널 (A·B)
- 84㎡ 평균 실거래가: 12.3억 [A | 국토교통부 실거래가 공개시스템 | 2026-09]
- 대출 가능 조건: 규칙 적용 결과 … [B | 규칙 테이블 | 2026-09]

## 의견 패널 (C·D·E)
- [C] 주장 요약 한 줄 (자체 표현) — 출처: https://… / 이해관계: 확인 못함 / 검증: 일부 확인
- [D] 매수 · 2024-03 · 후회한 점: … — 시장 국면: 하락기 / 인증: 미인증
- [E] 보수·기준·낙관 범위 … — 가정: 금리, 전세가, 입주 물량
```

## 규칙
1. `## 요약`과 `## 사실 패널`의 모든 `- ` 항목은 줄 끝에 `[A|B | 출처 | 기준일]` 태그가 있어야 한다(기준일은 YYYY-MM 또는 YYYY-MM-DD).
2. `## 의견 패널`의 모든 항목은 `[C]`, `[D]`, `[E]`로 시작한다.
   - C에는 `출처:`, `이해관계:`, `검증:` / D에는 `시장 국면:`, `인증:` / E에는 `가정:`이 있어야 한다.
   - 견해·후기·전망이 없으면 섹션 아래에 불릿 없이 "해당 없음" 한 줄만 적는다.
3. 수치는 근거 파일의 값을 그대로 옮긴다. `sources`에 실제로 쓴 근거 파일을 모두 적는다.
4. 금지 문구를 쓰지 않는다(`config/forbidden_phrases.json`). 특히 사실 패널에는 "저평가", "오를 지역", 순위 표현이 없어야 한다.
5. 사실과 견해를 한 문장에 섞지 않는다.

## 작성 후
`run_command`로 `python3 scripts/validate_board.py --draft {slug}`를 실행해 스스로 점검하고, 오류가 없을 때만 초안 경로와 사용한 근거 파일 목록을 오케스트레이터에게 보고한다. 게이트 단계에서 같은 검사가 다시 수행된다. 스크립트는 소스를 읽지 말고 `--help`부터 실행한다.
