# 추천 카드

## 카드 템플릿
```
후보: {지역}    내 구매력 {금액} / 대표 가격 {금액}
얻는 것:        내가 정한 1순위 기준에서 강한 지표 [A | 출처 | 기준일]
포기하는 것:    다른 기준에서 약한 지표 (같은 형식으로, 숨기지 않는다)
전제 조건:      적용 규칙 기준일 {날짜}, 금리·전세가·입주 물량 가정
틀릴 수 있는 이유: 이 추천을 무너뜨릴 수 있는 변수
근거 보기:      이 카드에 쓰인 A·B 지표 목록과 링크
```

## 지표 팩 스키마 (`data/board/pack/regions.json`)
브라우저 계산기가 읽는 입력이다.
```json
{"as_of": "YYYY-MM", "regions": [
  {"region_id": "songpa", "name": "송파구", "representativePrice": 0,
   "regulated": false,
   "metrics": {"school": 0.0, "commerce": 0.0, "station": 0.0, "price_path": 0.0},
   "evidence": ["data/re-market-data/songpa_raw.md"]}
]}
```
- `metrics`는 높을수록 좋은 값으로 정규화한다. 정규화 방식(예: 지역 간 백분위)은 방법론 페이지에 공개한다.
- `representativePrice`는 사용자가 고른 면적·연식 조건의 대표 실거래가(원)다. 출처와 기준일은 `evidence` 파일에 있다.
- `regulated`는 규제지역 여부이며 출처가 있어야 한다.

## 대안 경로 카드
청약(자격 확인 링크), 정책대출(조건은 규칙 테이블에서), 전월세 유지 후 재평가, 저축 목표 계산(부족액 ÷ 월 저축액으로 목표 시점), **지금 사지 않기**. 사지 않는 선택도 정당한 카드로 둔다.

## 하지 않는 것
- 단일 종합점수·순위, "오를 지역", "저평가", "지금이 매수 타이밍", 확률 수치.
- 예산 초과 후보를 추천 목록에 노출하기(참고 영역에 부족 금액과 함께 분리).
- 견해·후기(C·D·E)를 카드 근거로 쓰기. 필요하면 링크로만 연결한다.
