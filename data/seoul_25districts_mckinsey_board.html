STRATEGIC TAKEAWAY 01

상급지 전세가율 분화와 안전마진 형성

강남·서초는 평당 1.4억~1.8억 원대로 상승했으나 전세가율이 41%대로 갭 부담이 큽니다. 반면 송파·마포·성동·양천은 전세가율 48%~52%를 지지선으로 확보하여 LTV 50% 적용 시 3년 기대 ROI가 +22%~+26%로 실익이 가장 높습니다.

STRATEGIC TAKEAWAY 02

주담대 금리 4.39%와 DSR 2단계 여파

한국은행 기준금리 긴축 기조 하에 15억 원 기준 월 이자 상환액은 약 280만~350만 원에 달합니다. 스트레스 DSR 2단계 강화로 인해 유동성 중심의 영끌보다는 실수요 소득 기반의 중가권(84㎡ 14억~18억)에 매수세가 결집됩니다.

⚖️ 신호 판정 기준 통일 (단일 getSignal 엔진 규격)

부동산 신호등은 주관적 편향을 배제하고, 동일 지표 구간에서 모든 자치구 및 단지에 동일한 결과를 도출하기 위해 다음의 단일 정량 판정 공식을 적용합니다.

// [단일 공통 신호 판정 알고리즘] function getSignal(item) { const jeonse = parseFloat(item.jeonseRate); // 전세가율 (%) const risk = parseFloat(item.riskScore); // 투자 리스크 지수 const trend = parseFloat(item.trendScore); // 트렌드 모멘텀 지수 // 1) 🟢 매수고려 (Buy) // 조건: 트렌드 모멘텀 ≥ +1.0 AND 리스크 지수 ≤ +0.6 AND 전세가율 ≥ 50.0% // 의미: 거래 회복 탄력이 확실하며 전세가 방어로 안전마진 확보 if (trend >= 1.0 && risk <= 0.6 && jeonse >= 50.0) { return { code: 'buy', label: '매수고려', bg: '#EAF3DE', text: '#27500A' }; } // 2) 🟡 주의 (Caution) // 조건: 리스크 지수 ≥ +0.7 OR (전세가율 40.0% ~ 49.9% 구간) // 의미: 신고가 지속 지역이라도 갭 확대 및 금리 이자부담 가중, 선별 접근 else if (risk >= 0.7 || (jeonse >= 40.0 && jeonse < 50.0)) { return { code: 'warning', label: '주의', bg: '#FAEEDA', text: '#854F0B' }; } // 3) ⚪ 관망 (Watch) // 조건: 트렌드 모멘텀 ≤ +0.9 OR 전세가율 < 40.0% // 의미: 거래량 정체 및 매수 심리 냉각, 무리한 진입 지양 및 추가 방향성 확인 else { return { code: 'watch', label: '관망', bg: '#FFFFFF', text: '#5F5E5A', border: '#B4B2A9' }; } }

🔍 변경 전/후 비교 검증: 성남시(분당) vs 영등포구

이전 시스템에서는 비슷한 50~55% 전세가율 구간에서 성남시가 "주의", 영등포구가 "매수고려"로 불일치했던 문제가 있었습니다. 통일된 알고리즘 적용 결과를 비교합니다.

경기 성남시 (분당/판교) 변경 전: 일괄 🟡 주의
• 지표: 전용 84㎡ 17.8억 | 전세가율 51.6% | 모멘텀 +1.6 | 리스크 +1.0
• 기존 문제: 판교푸르지오그랑블(51.6%), 정자 파크뷰(55.3%) 등 전세가율 50% 이상 우량 단지까지 자치구 리스크 지수(+1.0)에 묶여 일괄 "주의" 처리됨.
• 개선 후: 자치구 단위는 고평가 리스크(+1.0)로 🟡 주의를 유지하되, 전세가율 50% 이상 단지는 🟢 매수고려로 객관적 분리 판정.
서울 영등포구 (여의도/당산) 변경 후: 일관된 🟢 매수고려
• 지표: 전용 84㎡ 15.2억 | 전세가율 52.8% | 모멘텀 +1.4 | 리스크 +0.6
• 판정 일치성: 모멘텀 ≥ +1.0, 리스크 ≤ +0.6, 전세가율 ≥ 50.0%의 3대 요건을 모두 충족하여 안정적 매수고려 구간에 정확히 부합.
• 결론: 성남시 판교 50% 이상 단지와 영등포구 52% 단지가 동일한 매수고려 임계값 규칙 하에 완벽하게 일관성을 유지함.
