데이터 수집부터 퀀트 분석, 의사결정 판정, 최종 리포트 및 이메일 발송까지 유기적으로 연결된 4단계 자율 에이전트 파이프라인과 MCP(Model Context Protocol) 아키텍처 매뉴얼입니다.

4-Stage Agent Pipeline (자율 에이전트 파이프라인)
📡

데이터 수집가

re-data-collector
"정확한 원천 데이터를 빠짐없이 수집하여 분석의 기반을 다집니다."
  • MCP 도구를 호출하여 국토부 실거래가 조회
  • 한국은행 ECOS 기준금리 및 금리 전망 API 수집

트렌드 분석가

re-trend-risk-analyst
"수집된 원시 데이터 속에서 숨겨진 패턴과 리스크 점수를 도출합니다."
  • 원자재 파일을 읽어 전세가율 및 평당가 트렌드 분석
  • 금리 민감도 및 학군 프리미엄 기반 리스크 스코어링 (0~100점)
  • 객관적인 퀀트 지표를 점수표 형태로 저장
⚖️

판단 엔진

re-timing-judge
"감정을 배제하고 오직 규칙과 점수에 기반하여 냉철한 매수/관망 신호를 판정합니다."
  • 트렌드 점수를 읽고 사전에 정의된 알고리즘 룰셋 적용
  • 🟢매수고려 / 🟡주의 / 🔴관망 3단계 교통신호 판정

  • 결론-이유-할일 3단 구조의 직관적인 브리핑 문서 작성

  • Gmail 인라인 렌더링 호환 이메일 템플릿 생성 및 정기 발송 자동화

MCP (Model Context Protocol) 툴킷 서버

에이전트들이 외부 세상(API, DB, 메일서버)과 소통할 수 있도록 권한과 도구를 제공하는 핵심 인프라 계층입니다. 현재 부동산 전용 로컬 서버 및 IpziTalk 클라우드 플러그인이 연동되어 있습니다.

작동 위치: /MCP/realestate-server.js

📡 Public API Connectors

국토교통부 실거래가 OPEN API, 한국은행 ECOS 통계, 나이스(NEIS) 학군 정보 실시간 조회

📨 Nodemailer Mailer

SMTP_USER, SMTP_PASS 환경변수 기반 무인 백그라운드 자동 메일 발송 모듈

End-to-End 작동 관계 및 워크플로우
STEP 01
[trigger] 사용자의 "/매수타이밍" 명령 또는 스케줄러(매주 목요일 09:00)에 의해 파이프라인 가동
STEP 02
[re-data-collector]가 MCP 서버를 호출하여 25개 자치구의 최신 실거래가 및 ECOS 금리 데이터를 Fetch ➔ mapo_raw.md 저장
STEP 03
[re-trend-risk-analyst]가 원자재를 읽고 트렌드 분석 및 학군/금리 리스크 스코어링 진행 ➔ mapo_scores.md 저장
STEP 04
[re-timing-judge]가 스코어를 기반으로 규칙 엔진 가동, LTV 50% ROI 산출 및 매수/관망 신호 판정 ➔ mapo_signal.md 저장
STEP 05
[re-briefing-reporter]가 최종 신호들을 취합하여 맥킨지 스타일의 2-Page HTML 대시보드 및 인라인 이메일 템플릿 빌드
STEP 06
